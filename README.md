# Machine learning-based prediction of influent Chemical Oxygen Demand (COD) for Food-to-Microorganism (F/M) ratio estimation and Sludge Propagation Optimization in Wastewater Treatment

## 📌 Background

<p align="justify"> Preparing wastewater treatment plant proposals requires coordination between the design and commercial teams, where technical design, equipment selection, quantities, and specifications are developed before project costing and quotation. However, strict submission deadlines and budgetary inquiries that only require an initial cost estimate can limit the time available for detailed proposal preparation, creating a need for a preliminary approach to project cost estimation without completing the full technical design.

## ❗ Problem Statement

<p align="justify"> Since budgetary costs are generally developed after the technical design and equipment requirements have been established, clients requesting only preliminary estimates may need to wait for the completion of the technical and commercial proposal process. This can increase the workload of both the design and commercial teams, particularly when multiple projects must be evaluated within short deadlines during peak periods such as the third and fourth quarters.

## 🎯 Project Objectives

This project aims to develop a data-driven approach for predicting wastewater treatment plant project costs to support budgetary estimation and improve the efficiency of the technical and commercial proposal process with the following objectives:

- To collect, clean, preprocess, and analyze historical wastewater treatment plant project data in order to identify relevant project parameters associated with overall project cost.
- To develop and evaluate Machine Learning Models for predicting wastewater treatment plant project costs
- To validate the predicted project costs by comparing model predictions with actual historical project costs using appropriate statistical and predictive performance metrics.
- To evaluate the potential of the proposed predictive model as a decision-support tool for reducing the time required for budgetary cost estimation.
